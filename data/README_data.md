## Data and weights

The dataset used in the paper is stored as a [`datasets.Dataset`](https://huggingface.co/docs/datasets) folder, which uses about 10× less storage.
Open it with the `datasets` library and save it to a local folder (see `prepare_dataset.py`).

The data is also available [here](https://drive.google.com/drive/folders/1JCaaaJOvfReaqPbIBVtVnPAH7TVc4AA5?usp=sharing).
The trained weights for the VAE and the U-net are stored in the same folder.
